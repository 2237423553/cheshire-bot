# 会话用量统计

用户想看本次会话或某个历史会话的模型用量时，按下面步骤执行。

## 步骤

1. 运行统计脚本。脚本路径相对**加载本技能时工具返回的技能基目录（Base directory）**，不要猜测安装路径：

   ```
   python -I "<技能基目录>/scripts/usage.py"
   ```

   - 默认统计「最近修改」的会话文件——在当前会话里运行时就是当前会话。
   - 可选参数：
     - `--list`：列出本机所有会话文件；
     - `--session <ID片段或jsonl路径>`：统计指定会话（如 `--session sess_9ee05bb7`）；
     - `--json`：输出原始 JSON（含分模型明细），适合需要精确数字时使用。

2. 把脚本输出的 Markdown 用量面板**原样**展示给用户——它是最终结果，不要重排、不要翻译、不要改写数字。若脚本报错（找不到会话文件、没有记录等），如实转述错误内容，不要编造数字。

## 说明（用户问起时再解释）

- **自动页脚**：本插件注册了 UserPromptSubmit 钩子，每次用户发消息时自动运行 `usage.py --footer` 并把累计用量注入对话，模型据此在每条回复末尾附上一行 `— 367.9万 Tokens · 71.5 Token/秒`（数字截至该条回复开始前，不含回复自身）。页脚缺失时用户可运行 `/usage` 看完整面板。
- 数据源：`~/.zcode/cli/rollout/model-io-<会话ID>.jsonl`，ZCode 的模型 I/O 日志，每行一次模型调用（含 usage 与耗时）。可用环境变量 `ZCODE_ROLLOUT_DIR` 换数据目录。
- 「推理 Tokens」按字符构成估算（CJK 字符 ×1 + 其他字符 ×0.25），日志里没有 API 精确的推理 token 数。
- 「模型生成 TPS」= 输出 Token ÷ 各次请求耗时之和；「端到端吞吐」= 输出 ÷ 会话首末时间跨度。流式的首 Token 耗时日志中不存在，因此不展示。
- 费用是本地估算：仅当 `scripts/prices.json` 里给该模型配了单价（US$/1M tokens）才显示，否则显示 —。用户可自行编辑该文件补价格。
