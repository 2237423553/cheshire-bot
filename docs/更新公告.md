## English Summary (latest)

**Oct 30, 2026 — self-check slimmed to 8 points:** the QQ-injection chain is no longer part of the self-check report — the admin WebUI listening check, both OneBot port checks and the QQ identity probe were removed. SnowLuma and QQ being closed is a perfectly normal state, and the old report turned red with "waiting for injection" nagging every time it ran against that reality; injection/link state belongs to the admin WebUI's connection indicators, not the self-check table. The report is now: runtime / config / QQ process / SnowLuma process (uniqueness) / bot process / LLM round-trip / Exa search / menu lottery — and it passes cleanly 8/8 even with QQ closed. Doc references to "12-point self-check" were updated across README and docs/01 accordingly.

**Oct 30, 2026 — waves 2+3, review fixes complete (15 more):** the remaining findings from the four-agent review are all in. **Error classification unified**: moderation/quota/key/rate/timeout detection lived in five hand-copied regex sets that had already drifted (image/video paths couldn't recognize `sensitive`-class blocks; "额度打满" escaped the TTS quota check) — now one `classifyUpstreamError` table in providers.mjs classifies from `message ?? code ?? JSON.stringify`, so provider error `code` fields like `content_policy_blocked` / `insufficient_quota` match too, and callers keep their own human phrasing. **Tool-count exhaustion no longer returns silence** — the final round used to emit an empty string and the group heard nothing; a fallback line now suggests rephrasing. **Probe suite de-flaked**: auth/quota 4xx errors no longer misread as "thinking param rejected" (the old `/invalid/` regex ate every 4xx), and new-endpoint response shapes — content as an array of parts, a `reasoning` field instead of `reasoning_content` — no longer report a false "structure mismatch"; the CLI's two render paths now share one `formatSuite` source. **Three parallelizations**: multi-image/video downloads, reply-quote expansions and same-round tool calls run concurrently (image-heavy @ replies save 2–5 s; double-search rounds save 5–30 s). **War Thunder dual-domain racing** replaces the alternating 3×30s retry (worst case 90 s → ~15 s). **splitMessage** breaks on English-period-plus-space and hard-splits over-budget sentences. **Anti-lie gate tightened**: it only fires when the turn is actually about drawing, and forwarding semantics ("图已发出") left the trigger words. **Bilibili** guards all three bare `r.json()` calls (risk-control HTML → human message, not SyntaxError); its cache gains a 120-entry eviction, and the compressor session's prompt-token record gets cleaned. **Route error messages go through a `humanizeError` filter** (internal details never posted); all seven media sends unify into one `sendMediaSeg`; `applyProfile` rolls back the state write if the profile-mark write fails; the panel token check went timing-safe; the panel image card gained the Grok parameter set (aspect/resolution/quality). Deliberately left: route ordering for quote-image-as-reference needs a product decision, and the vidgen download copy is a non-issue at current sizes.

**Oct 30, 2026 — wave-1 review fixes, ten of them:** a four-agent code review produced 25 prioritized findings; the top ten are fixed. **Group-level serialization** — @routed heavy routes (draw/video/song/voice/main chat) now run through a per-group job queue; the old fire-and-forget handler let a second @ start a second full pipeline while the first was still thinking (5–60s), interleaving history writes; busy @s now get a "one sec, I'm busy" reply and queue up. **Search "daily" limit actually resets daily** — the counter previously only ever grew, so a bot running for weeks silently lost search forever. **Panel thinking-tier radio was a dead control** (the frontend sent `"auto"`-style strings, the server expected an object and silently fell back to "keep current"); normalized + profile saving now carries the tier. **The SSRF gate covered reads, not writes** — /api/save, profile upsert/apply and the media-API save endpoint now validate URLs before any pre-shared-key URL lands in runtime state. **`cleanToolArtifacts` stopped eating real code fences** — it now strips only fenced content that smells like a fake tool-call JSON or pseudo-tags. **Key lists unified**: switches and media-API keys now have a single source (`switches-meta.mjs` / `config.mjs` export), which incidentally gave the panel the missing `tts` switch and three TTS keys (voice ID / singing endpoint / singing key). **Media association window**: 10 → 6 turns, sticky threshold 8 MB → 2 MB, a new 24 MB total base64 budget inside the window, and out-of-window/degraded images are released from memory in place — the largest per-request token sink (~30–60k tokens of re-uploaded images in busy groups). **Context compression moved after the reply** instead of blocking the user before it. **vidgen**: a submit that returns no request_id now aborts immediately (the old retry loop risked double-committing and double-billing), polling now reads HTTP status (two 404s → "task gone", error bodies classified immediately, unknown statuses wait instead of failing), and the poll interval ramps 5s → 15s (~45 requests max instead of 96). **callLLM checks `r.ok` before parsing** so a 502 HTML page no longer leaks "Unexpected token" into the group.

**Oct 29, 2026 — random Cheshire images + the main-line LLM call finally gets a timeout gate:** @ the bot with `随机柴郡图` / `来张柴郡猫猫` / `抽一张柴郡表情包` and she fetches a random image from GitHub repo `1143520/chaijun` (the backend of the mao.1143520.xyz fan site, 1000 Cheshire memes) and posts it — a fully scripted route, the model never gets involved. A live-network reality check came first: raw.githubusercontent, both jsDelivr hosts and the gitmirror mirror are all blocked on this network, and only api.github.com is reachable — so downloads go through the contents API with the raw media type, and the random pool is capped at files ≤1 MB (956 of 1000, verified stable). Also fixed from the evening's "stuck bot" incident: `callLLM` was the last timeout-less fetch on the main path (a stalled endpoint could hang an @-reply forever) — now capped at 5 minutes, and timeout-class errors are translated into plain Chinese before reaching the group (no more raw "The operation timed out."), with imggen/tts/vidgen now accepting the AbortError alias too.

**Oct 27, 2026 — voice stack moves to ByteDance Doubao:** talking switched from MiMo to the **Doubao voice model 2.0** (commander-picked voice `zh_female_roumeinvyou_uranus_bigtts`) via ByteDance's official seed-tts protocol — not OpenAI-compatible: `X-Api-Key` + `X-Api-Resource-Id` headers, a `req_params` wrapper, and an HTTP-chunked response of concatenated JSON objects that has to be split by brace-depth scanning. Two protocol quirks are welded in code: the stream-end signal is `code=20000000 / message="OK" / data=null` (the official docs claim any non-zero code is a failure — reality disagrees, so the body wins), and the streamed WAV header carries a placeholder RIFF size, so the format is mp3. The voice design now travels as `context_texts` speech instructions (exclusive to 2.0 voices, not billed); MiMo stays as a fallback. **Tone became reactive**: `generateSpeech` gained an `upstream` param that quotes the user's triggering message into `context_texts` (official Query-Response pattern — referenced, not synthesized), and a real adapter bug got fixed along the way: `context_texts` honors **only its first element**, so base design + tone directive + upstream must be merged into a single string or the rest is silently dropped. **Auto-voicing threshold lowered 300 → 50 chars** — only short quips get voiced first, longer replies stay as plain chunked text (the explicit `语音：` route is unaffected). **Singing moved to Seed Audio 1.0** (Doubao's audio-generation model): `POST /api/v3/tts/create` with a *flat* `{ model, text_prompt }` body — a different shape from the TTS endpoint — responding `{ audio: base64 wav }`; it's prompt-driven so lyrics are guided rather than literal (it can't be forced to sing exact lines), comes with a 60-minute free trial, and `singCreate` only accepts a custom `ttsSingUrl` that points at bytedance.com (mis-feeding the MiMo borrow endpoint can't blow up the request shape); the MiMo preset-voice `(唱歌)` path remains as the fallback for non-Volcano setups.

**Oct 24, 2026 — review hardening:** an external code review produced 13 findings, all verified real, fixed in three batches. **① Timeout gates** where they were missing: the Exa MCP rpc (a hung endpoint used to stall an entire @-reply silently, zero errors) and the panel's model-list fetch; the anti-lie gate now echoes the model's lying message back before the call-out (it used to "get scolded out of nowhere"); the `语气指令` tone line and the `〔视频描述〕` trailer line are now extracted order-independently — the old parser could swallow the video description, and since the video itself never enters context that meant permanent memory loss; the context compressor now calls the LLM bare (no persona, no tools). **② Key sinking:** config.mjs carries placeholders only — byte-identical between the live copy and this repo, so mirror sync is now a plain directory copy with zero manual steps; real keys live in gitignored runtime files (`secrets.json`: LLM key + OneBot tokens; `mediaapi.json`: all image/video/TTS fields including the voice design), and the panel gained a TTS card. **③ SSRF gate:** `assertSafeUrl` in providers.mjs — http/https only, rejects loopback/private/link-local hosts by literal check *and* by DNS resolution (anti-rebinding), explicit host:port allowlist; wired into the bot's media downloader (group members can stuff URLs into messages — and it also gained its missing 60s timeout) and the panel's three fetch-on-URL endpoints, with Ollama's 11434 as the only local exemption.

**Oct 22, 2026 — draw-route & image-API fixes:** the draw-intent gate now accepts detailed requests up to 5000 chars (the old 80-char cap silently rejected numbered requirement lists and let the model "mouth-draw" a fake success); the image-prompt translator got new iron rules — numbered/negative requirements must survive into the prompt item by item, equipment nicknames map to official English names (e.g. Challenger 2 "Black Night"), 40–120 words; `imggen` now supports both OpenAI-style (`size`/`quality`) and xAI Grok-style (`aspect_ratio`/`resolution`/`quality`, defaulting to medium — omitting quality means auto=low) parameter sets; the config panel's image/video cards gained a model-list fetch button with searchable dropdown (new `POST /api/media-models`, via `mediaModelsUrlOf`).

**Oct 21, 2026 — API panel upgrade:** local web config panel (bind 127.0.0.1, token-protected, keys always masked) with provider presets (OpenCode / CommandCode / DeepSeek / Kimi / BigModel / SiliconFlow / OpenRouter / Ollama); automatic 4-point probe (basic generation / thinking modes / tool calling / vision) via panel or `--probe`; per-message feature switches (`switches.json`, effective instantly, no restart); media-gen API config (`mediaapi.json`, restart required); custom prompts (`prompt.json`); config profiles. Earlier today: text-to-video (async submit/poll/download, 15s cap, download retry), text-to-image with intent-forced routing, honest error reporting for audit blocks / rate limits / quota exhaustion (relay disguises "no money" as HTTP 429), OneBot token leak remediated (history rewritten + force push + rotated + verified via fresh clone).
