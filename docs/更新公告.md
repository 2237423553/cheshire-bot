## 2026-10-21（下午-傍晚）

### 🎬 文生视频上线
- 新增 `vidgen.mjs`：Grok 通道（OpenAI 兼容异步任务制：提交 → 轮询 → 下载成片 mp4）
- 群里 @ 机器人说「生成××视频/影片/动画」即触发**意图强制路由**：脚本接管（prompt 翻译 → 提交 → 轮询 → 下载 → 发群），模型没有「装成功」的机会；翻译层有否决权，不像生成视频的请求放行正常对话
- **图生视频**：引用/附带图片再要求生成视频，自动按图生视频（`image_url` = data URL 实测通）
- **15 秒上限**：`vidgenMaxSeconds` 脚本硬检查，超限成片弃用不发；提交默认不带 duration 走自动时长（≈8s）省额度
- **下载自动重试**：成片下载遇 429/5xx/超时自动重试最多 4 把（有 Retry-After 按它等）——任务已完成、费用已扣，不再让一次限流白扣一把额度
- **业务总闸 `vidgenEnabled`**（默认 true）：设 false 后 @ 点视频直接回「暂停营业」，不进普通对话，防止模型嘴上承诺生成却零动作
- 生成视频端点提交加 502/503/504 重试；端点切 `sui-xiang.vip` 域

### 🖼 文生图上线
- 新增 `imggen.mjs` + `generate_image` 工具：OpenAI 兼容生图端点（b64_json 直发群）
- **画图意图强制路由**：@ 命中画图句式 → 脚本接管（翻译 → 生图 → 发群），三道判定门 + 翻译层否决权；被否决的放行正常对话
- **改稿路由**：画图成功后 10 分钟内 @ 说「改一下/性别错了」等修改词，自动带上次 prompt 重新生成
- **防谎报闸（坑 34）**：模型嘴上说「画好了/这就画」但没真调工具 → 出口检测打回重画
- 生图 429 读 Retry-After 等待重试；**失败提示直发群**（失败原因不再只进日志）

### 🔧 修复
- 图片发送超时：SDK 默认 30s 掐 2~3MB 慢传 → 发图 120s / 发视频 300s 显式超时（坑 35）
- 画图闸否决名单补「视频/影片/动画」（此前引用图片要求生视频会被画图路由抢走）
- 生图内层函数残留旧变量名导致 ReferenceError（教训：改动必须真调接口验证）

### 🔒 安全
- 发现 OneBot 双令牌曾以真值存在于早期提交历史 → **全历史重写 + force push 覆盖远端 + 令牌轮换**，复验（线上重新克隆死查 + 老令牌 401）确认彻底闭环
